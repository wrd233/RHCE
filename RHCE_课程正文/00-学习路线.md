# 先把学习路线放在眼前

我们从 RHCSA 已经熟悉的系统对象开始：软件包、服务、用户、文件、存储。每学一个 Ansible 能力，我会先说明它要解决什么问题，再写一个可以检查的例子，最后指出这套 19 题模拟练习在哪里用到它。你可以只靠这份网站作为主线阅读；章节末尾的课堂记录是核对细节用的附录。

页面上方的五步路线，可以贯穿每一章：先看主机和对象，再看数据与控制流，最后到目标节点验收。做题时先看清对象和状态，模块参数可以查本机文档补全。

模拟题中的 `workstation`、`servera` 等主机名、`/home/devops/ansible`、仓库 URL、口令和镜像地址都是这套练习的条件。它们帮助我们把概念落到具体题上，却不能直接推断你参加的正式考试一定使用同样环境。正式考试的任务与可用工具以届时题面和官方考试目标为准。

页面中，“精确一点”用于纠正容易误解的简化表述，“考试连接”把知识点映射到模拟题，“随堂想一想”先让你自己判断，再展开答案。每道练习下都有一处本机保存的思考记录，可以导出为 Markdown；先写下自己的判断再看答案，会比直接复制 YAML 更稳。
